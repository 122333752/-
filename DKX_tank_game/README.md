# DKX 坦克大战

一个使用 Python + Pygame 制作的简单坦克大战小游戏。

## 已实现功能

- 玩家坦克移动
- 玩家发射炮弹
- 3 个敌方坦克简单 AI
- 敌人会移动并自动射击
- 墙体障碍和碰撞检测
- 玩家与敌人均有 3 点生命
- 胜利 / 失败判定
- 按 R 重新开始
- 地图中央墙体拼出姓名缩写 `DKX`
- 界面右上角显示 `地图身份标识：DKX`

## 操作方法

- `WASD` 或方向键：移动
- `空格`：射击
- `R`：游戏结束后重新开始
- `ESC`：退出

## 运行方法

先安装 Python 3，然后在项目目录中执行：

```bash
pip install -r requirements.txt
python main.py
```

## 作业说明

本项目不依赖额外图片素材，地图、坦克和障碍全部使用 Pygame 图形绘制，方便直接运行与提交。
